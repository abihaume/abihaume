# Ume Abiha

Quantitative Biology student at Heinrich Heine University Düsseldorf, focused on cancer bioinformatics.

I analyze cancer genomics data end to end: from raw RNA-seq expression data and clinical metadata to differential expression, machine learning and drug-target discovery.

### Featured projects

| Project | What it does | Stack |
| --- | --- | --- |
| [TCGA Breast Cancer Gene Expression Analysis](https://github.com/abihaume/tcga-brca-gene-expression-analysis) | Tumor vs normal analysis of 1,211 TCGA-BRCA samples and 20,530 genes: 4,225 differentially expressed genes (FDR < 0.05), PCA, K-Means clusters matched to PAM50 subtypes, and a tumor classifier (ROC-AUC 0.99, cross-validated) | Python, pandas, SciPy, scikit-learn, Databricks |
| [Drug Repurposing for Breast Cancer](https://github.com/abihaume/drug-repurposing-brca-dgidb) | Maps the top 100 dysregulated genes to 816 drug-gene interactions via the DGIdb GraphQL API and ranks 129 direction-aware candidates; recovers known breast cancer drugs such as doxorubicin | Python, pandas, NetworkX, DGIdb API, Databricks |
